# Corner Table — café site template

Minimal restaurant/café layout inspired by clean settings-style UI: light gray page, white cards, underline tabs, grouped lists.

## Stack

- React 19 + TypeScript + Vite
- React Router
- SCSS (design tokens in `src/styles/_variables.scss`)
- Lucide icons

## Run

```bash
npm install
npm run dev
```

## Customize

- Copy and venue details: `src/config/site.ts`
- Colors and radius: `src/styles/_variables.scss`
- Pages: `src/pages/*`

Blueprint lives in the sibling `blueprint/` folder — this project is independent.
