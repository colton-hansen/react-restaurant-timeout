# План — одностраничник «Тайм-аут»

Полный план реализации: см. Cursor plan `timeout_landing_rebuild` или историю чата.

Кратко:

- Vite + React 19 + TS + Tailwind 4
- Маршруты: `/`, `/agreement`
- Бронь только `tel:` / VK / WhatsApp
- Контент с [timeout-sestroretsk.ru](https://timeout-sestroretsk.ru/)
- Визуал: бумажный фон и терракота, референс [Kofee](https://www.figma.com/design/KrvOmGQN0d345LHQHnIfXY/Kofee---Cafe-Web-Design-Free-Template--Community-?node-id=1-2)

Запуск: `npm run dev`
