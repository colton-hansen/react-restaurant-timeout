# Дизайн — Тайм-аут

Референс: [Kofee — Cafe Web Design](https://www.figma.com/design/KrvOmGQN0d345LHQHnIfXY/Kofee---Cafe-Web-Design-Free-Template--Community-?node-id=1-2) ([демо](https://demo.templatesjungle.com/kofee/)).

Ретро-кафе: бумажный фон, терракотовые кнопки, узкие uppercase-заголовки, полноширинное фото и белая карточка поверх. Контент — только «Тайм-аут», не меню Kofee.

## Токены

| Token | Value |
|-------|-------|
| `--color-bg` | `#F5F4F2` |
| `--color-surface` | `#FFFFFF` |
| `--color-paper` | `#EDEBE8` |
| `--color-ink` | `#393330` |
| `--color-muted` | `#4F4844` |
| `--color-accent` / `--color-cta` | `#EE8542` |
| `--color-border` | `#D2CFCC` |

Шрифты: Alumni Sans (заголовки, лого, нав — кириллический аналог Bebas Neue), Source Serif 4 (текст).

## Секции главной

1. Тонкая полоса: слоган, телефон, адрес
2. Белая шапка: лого с терракотовым дефисом, uppercase-навигация
3. Hero — фото на всю ширину + карточка 50/50 (слоган / часы)
4. О нас — фото в наклонённом овале + факты
5. Меню — пунктир к цене, сканы
6. Отель / баня — карточки + tel
7. Карта и отзывы Яндекса / футер
